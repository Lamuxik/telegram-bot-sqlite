# Telegram Bot — заявки на услуги

Telegram-бот для обработки заявок клиентов и передачи их мастеру.

## Возможности

- клиент отправляет описание проблемы;
- заявка сохраняется в SQLite;
- мастер получает новую заявку;
- мастер может принять или отклонить заявку;
- статус заявки сохраняется в базе данных;
- уже обработанную заявку нельзя обработать повторно;
- мастер может посмотреть список новых заявок через `/new`.

## Технологии

- Python
- Aiogram
- SQLite
- Git
- GitHub

## Структура проекта

- `main.py` — логика Telegram-бота;
- `database.py` — работа с SQLite;
- `.env` — секретные данные;
- `.gitignore` — файлы, которые не должны попадать в Git.
